# MIRAAT (web)

The SIYANA control room: Next.js 16 App Router, Tailwind v4, Motion (`motion/react`), Lenis,
React Three Fiber. Run commands and architecture live in the repository root `README.md` and
`docs/ARCHITECTURE.md`.

```bash
cp .env.local.example .env.local && npm install && npm run dev
```

`npm run lint`, `npm run build`, and `node scripts/contrast.mjs` are the quality gates.
